NOOR AMJAD — GITHUB PAGES PORTFOLIO STARTER

This starter is designed to be published free using GitHub Pages.

PUBLISH IT
1. Create or sign in to a GitHub account at https://github.com/
2. Create a PUBLIC repository named exactly: YOUR-GITHUB-USERNAME.github.io
   Replace YOUR-GITHUB-USERNAME with your actual GitHub username.
3. In the new repository, select Add file > Create new file.
4. Name the file: index.html
5. Open the supplied index.html in a text editor, copy all its contents, and paste them into GitHub's editor.
   Alternative: upload index.html directly using Add file > Upload files.
6. Commit the changes.
7. Go to repository Settings > Pages.
8. Under Build and deployment, choose Deploy from a branch.
9. Select branch main and folder /(root), then Save.
10. Wait a few minutes, then visit https://YOUR-GITHUB-USERNAME.github.io

IMPORTANT
- The website repository and published website are public. Do not upload private records, identity documents, passwords, confidential company information, or private contact details.
- Replace all template notes, placeholder dates, email address, and LinkedIn link before sharing the website professionally.
- Do not claim a case study is complete until you have the actual work and can accurately describe your contribution.
- GitHub Pages is static hosting. This starter has no server, paid service, or database.
- Changes may take several minutes to appear after committing.

EDIT THE WEBSITE
The whole website is in one file, index.html. You can edit it in GitHub by opening the file and clicking the pencil icon, then committing your changes. For bigger changes, keep a backup of the original file first.
